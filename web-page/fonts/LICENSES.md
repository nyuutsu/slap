# Font licenses

All five families are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org), self-hosted so the page makes no request beyond its own origin. All but Sarasa are the latin subsets as served by Google Fonts.

- **Baloo 2** — Ek Type. Variable weight axis (400–800) in one file.
- **Nunito** — Vernon Adams, Cyreal, Jacques Le Bailly. Variable weight axis in one file.
- **Space Mono** — Colophon Foundry, for Google Fonts.
- **IM Fell English** — the Fell Types, digitally reproduced by Igino Marini.
- **Sarasa Mono J** — Belleve Invis, building on Iosevka; subset here from the full font.
