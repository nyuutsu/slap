# Font licenses

All four families are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org), self-hosted so the page makes no request beyond its own origin.

- **Baloo 2** — Ek Type. Variable weight axis (400–800) in one file; the latin subset as served by Google Fonts.
- **IM Fell English** — the Fell Types, digitally reproduced by Igino Marini; the latin subset as served by Google Fonts.
- **Nunito** — Vernon Adams, Cyreal, Jacques Le Bailly. Variable weight axis in one file; the latin subset as served by Google Fonts.
- **Sarasa Mono J** — Belleve Invis, building on Iosevka; both weights subset here from the full font.
